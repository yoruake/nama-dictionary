# Nama · 多语言查词

给认真读外语的人用的划词词典。选中一个词、一个词组或整句，Nama 调用 DeepSeek，
返回四样东西：**发音注音 / 词源 / 中文词义 / 该词在这句话里的形态与句法作用**。

> **Nama** 取自粟特语的「书・文书」。项目早期叫 DeepLex，2026 年 7 月更名。
> 仓库里 `zotero-deeplex/` 目录和 `deeplex.js`、`deeplex.xpi` 等文件名仍保留旧名，只是没改而已，不影响功能。

一共两个版本，共用同一套提示词和同一种词条格式：

| | 位置 | 版本 | 用在哪 |
|---|---|---|---|
| 浏览器扩展 | 仓库根目录 | 0.6.3 | Chrome / Edge 等 Chromium 浏览器，任意网页 + YouTube / Netflix 字幕 |
| Zotero 插件 | `zotero-deeplex/` | 1.6.0 | Zotero 7 / 9 内置 PDF、EPUB 阅读器 |

主要面向波斯语、俄语、阿拉伯语、突厥语系、日语、中文，其他语言同样可用。

---

## 设计上的一个决定：只给「正文语言」的读音

这是 Nama 跟一般词典最不一样的地方，也是最容易被误认为 bug 的地方。

**注音只按你正在读的那门语言给，不给原语读音。** 你在读中文，文章里出现「织田信长」，
Nama 给的是 `Zhītián Xìnzhǎng` 而不是 `Oda Nobunaga`；「菩萨」给 `púsà`，它的梵语来源
只出现在「词源」一栏里。理由很简单：读者需要知道的是这个词**在这篇文章里怎么念**。

注音体系随正文语言切换：

- 汉字圈（中 / 日 / 韩 / 越）：拼音 / 罗马音 / 罗马字
- 梵语、巴利语及其借词：IAST
- 阿拉伯字母圈、西里尔圈、拉丁圈：IPA

语言由选区上下文判断，所以**连着上下文一起选，结果会准很多**——孤立的一个汉字或一个
阿拉伯字母词天生有歧义。

## 浏览器扩展

### 安装

1. 打开 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本仓库根目录
4. 已经打开的网页需要刷新一次

### 配置 API Key

点工具栏里的扩展图标打开设置页，填入你自己的 [DeepSeek](https://platform.deepseek.com) API Key，
保存。设置页里有「测试 API Key」，可以用一个测试词验证连通性。

模型固定用 `deepseek-v4-flash`，并显式关闭了思考模式（`thinking: disabled`）——
v4 默认开思考，查一个词要等好几秒，关掉之后才是可用的速度。

### 用法一：网页划词

在任意网页上用鼠标选中要查的词，查词卡片会浮现在选区旁边。

- 卡片**流式渲染**：先出词形，再逐字长出注音，然后词义、词源依次到位。还没到的字段显示 `…`。
- 点卡片上的星标收藏进生词本；已收藏的词再选一次就能取消收藏。
- 「重新分析」按钮常驻，改了提示词或想换个结果时点它，收藏和导出状态会保留。
- **页内高亮**（默认开）：生词本里的词在页面上带点线下划线，纯被动显示，不响应悬停和点击。
  收藏 / 取消收藏会即时增删下划线。匹配的是精确表面形式，不做词形还原。

### 用法二：视频字幕模式（YouTube / Netflix）

默认开启。在播放页上，Nama 用自己的字幕层就地覆盖原生字幕，**鼠标悬停在词上就查**。

- **鼠标进入字幕框自动暂停，离开自动续播。** 只有 Nama 自己暂停的才会自动续播——
  你按空格暂停的不会被莫名其妙地放下去。
- 悬停某个词 120ms 出词义卡片；鼠标移到卡片上时不收起、也不续播，所以收藏和「重新分析」点得到。
- 多字词、词组用**拖选**（汉字和假名是逐字可点的，没做分词）。

字幕有两种取法，会自动降级：

- **track 模式（首选）**：开播时把整条字幕轨抓下来，一次性断句建时间轴。跳句精确，
  显示的是**完整句子**。成功时左下角会闪一下「字幕已载入：N 句」。
- **live 模式（兜底）**：整轨拿不到时退回轮询 DOM，边看边攒。前跳只能试探，显示的是碎片。
  会闪「字幕轨未取到，已退回逐句模式」，具体原因在 console。

> 看到字幕「一个词一个词往外蹦」，先确认是不是退回了 live 模式——那是滚动字幕的原生行为。

快捷键（输入框内不触发）：

| 键 | 作用 |
|---|---|
| `←` / `A` | 上一句开头 |
| `→` / `D` | 下一句开头 |
| `S` | 重复本句 |
| `Q` | 开关「每句末尾自动暂停」 |
| `W` | 开关「合并成整句显示」 |
| `[` `]` | 调字号 |
| `Shift` + `↑` `↓` | 调垂直位置 |
| `Shift` + `←` `→` | 前后 5 秒微调 |

`←` / `→` 是**直接跳整句**，覆盖了播放器原本的 5 / 10 秒快进；想细调用 `Shift+←/→`。

### 设置项

设置页改完即时生效，不用刷新（字幕模式总开关除外，需要刷新播放页）。

| 设置 | 默认 | 说明 |
|---|---|---|
| 网页内高亮 | 开 | 生词本词条在网页上加点线下划线 |
| 视频字幕模式 | 开 | 总开关 |
| 每句末尾自动暂停 | 关 | 一句放完就停，练听力用 |
| 合并成整句显示 | 关 | 屏幕上把碎片攒成整句。**注意**：无论开关如何，传给模型的上下文一直是攒出来的整句 |
| 每句最长字数 | 80 | 30–240。长度本身不制造断点，只决定在哪个安全点（句末标点 / 从句标点 / 停顿）上断 |
| 字号 | 28px | |
| 垂直位置 | 12% | 离画面底边的百分比，锚在 `<video>` 上，不跟着控制栏跳 |
| 字体 | 系统 | 下拉选或自己填 font-family |
| 字幕衬底 | 描边 | 描边 / 半透明底 / 无 |

### 生词本与 Anki 导出

设置页点「打开生词本」。支持搜索、按语言筛选、时间筛选（今天 / 近 7 天 / 近 30 天）、
导出状态筛选（未导出 / 已导出）、排序、展开详情、多选批量删除（勾选框 + Shift 范围选）。

点「导出 CSV」下载 `vocabulary_YYYY-MM-DD.csv`，**所见即所导**——跟随当前筛选。
导出后自动标记为「已导出」，下次筛「未导出」就只导新词。

导入 Anki：

1. 文件 → 导入 → 选该 CSV
2. Note Type 选「基础」
3. 字段映射：第 1 列 → 正面，第 2 列 → 背面，第 3 列 → 标签
4. **重复项处理选「保留(Preserve)」**

正面埋了隐藏的词条 id 用于去重，`#tags column:3` 会自动映射标签。

## Zotero 插件

在 Zotero 内置的 PDF / EPUB 阅读器里选词查询，结果显示在文字选择弹窗中。
上下文取选区所在段落（限 400 字符）。

### 安装

用仓库里打好的 `zotero-deeplex/deeplex.xpi`：

1. Zotero → **工具(Tools) ▸ 插件(Add-ons)**
2. 右上角齿轮 ⚙ → **Install Add-on From File…** → 选 `deeplex.xpi`
3. 无需重启

> 从 DeepLex 升级过来的：插件 id 换了，Zotero 会视为新插件，**旧的「DeepLex」需要手动删除**。
> 生词本和 API Key 会在首次启动时自动迁移，不会丢。

### 配置与用法

- **设置 Key**：工具(Tools) ▸ 「Nama: 设置 DeepSeek API Key」
- **查词**：打开 PDF / EPUB，选中文字，卡片出现在工具条下方
- **生词本**：工具(Tools) ▸ 「Nama: 打开生词本」，功能与浏览器版一致
- **导出 Anki**：生词本里点「导出 CSV (Anki)」，文件存到**桌面**
- **排错**：帮助(Help) ▸ 调试日志 ▸ 查看输出，搜 `[Nama]`

### 自己打包

`.xpi` 就是个 zip，**三个文件必须在压缩包根目录**，不要多套一层文件夹：

```powershell
Compress-Archive -Path manifest.json,bootstrap.js,deeplex.js -DestinationPath deeplex.zip -Force
Move-Item deeplex.zip deeplex.xpi -Force
```

改版本号时注意：**`manifest.json` 必须是 UTF-8 无 BOM**。PowerShell 的
`Set-Content -Encoding utf8` 会写进 BOM，Zotero 会直接判定清单无效。

## 隐私

- API Key 只存在本机：浏览器版在 `chrome.storage.local`，Zotero 版在偏好 `extensions.nama.apiKey`。
- Key 不会上传到任何第三方，只在调用 DeepSeek 时作为认证头发给 DeepSeek。
- 查词时会把**选中的词和自动提取的上下文句子**发给 DeepSeek 用于生成分析，仅此而已。
- 查词记录、生词本、缓存全部保存在本地。
- **没有远程统计、埋点或自建后端。** 代码里也不含任何 Key。

## 权限

| 权限 | 用途 |
|---|---|
| `storage` | 保存 API Key、查词缓存和生词本 |
| `activeTab` | 最小标签权限 |
| `https://api.deepseek.com/*` | service worker 调 DeepSeek |
| `https://www.youtube.com/api/timedtext*` | 下载 YouTube 字幕轨 |
| `https://*.nflxvideo.net/*` | 下载 Netflix 字幕轨（走后台是为了绕开 CDN 的 CORS，下载地址有域名白名单） |
| `<all_urls>` content script | 在网页上监听选词、显示卡片 |

字幕相关的主世界脚本（`subtitle-bridge.js`）**只读不写、不发请求**，唯一的工作是把
页面 JS 里的字幕轨地址 `postMessage` 回来——内容脚本在隔离世界读不到这些。

## 已知局限

- 字幕模式靠 DOM class 取字幕，YouTube / Netflix 改前端就会失效；坏了先查
  `.ytp-caption-segment` 和 `.player-timedtext-text-container` 这两个选择器。
- 字幕模式只在主框架生效，别站嵌的 YouTube iframe 不接管。
- 自动字幕若既无标点、cue 之间又无停顿，断句只能靠启发式，可能断在介词后面。
- 页内高亮：被拆进多个内联标签的词匹配不到；跨标签页的高亮不实时同步，需刷新。
- 提示词改动只对**新查的词**生效，旧词要点「重新分析」才更新。
- 浏览器版流式渲染，Zotero 版是一次性返回（Zotero 沙箱里没有 `fetch`）。

## 项目结构

```
├── manifest.json            MV3 清单
├── background.js            service worker：DeepSeek 调用、提示词、解析、词条存储
├── content.js / .css        网页划词卡片 + 页内高亮
├── subtitle.js / .css       视频字幕模式
├── subtitle-bridge.js       主世界脚本，取整条字幕轨的地址
├── options.html/js/css      设置页
├── vocabulary.html/js/css   生词本
├── icons/
└── zotero-deeplex/          Zotero 插件
    ├── manifest.json
    ├── bootstrap.js
    ├── deeplex.js           全部逻辑
    └── deeplex.xpi          打包产物
```

## 词条数据结构

```js
{ id, word, translit, etymology, meaning, form, lang, context, timestamp, starred, exportedAt }
```

`word` 存的是**你选中的原文词形**，不是模型返回的词典形——页内高亮要靠它做精确匹配。
