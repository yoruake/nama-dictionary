# Nama · 多语言查词

给认真读外语的人用的划词词典，Manifest V3 浏览器扩展。在网页上选中一个词、一个词组或整句，
Nama 调用 DeepSeek，返回四样东西：**发音注音 / 词源 / 中文词义 / 该词在这句话里的形态与句法作用**。

查过的词可以一键收藏进生词本，导出成 Anki 能直接导入的 CSV。

主要面向波斯语、俄语、阿拉伯语、突厥语系、日语、中文，其他语言同样可用。
当前版本 **0.9.0**。

> **Nama** 取自粟特语的「书・文书」。项目早期叫 DeepLex，2026 年 7 月更名。

## 安装

### 1. 下载

点仓库右上角绿色的 **Code ▸ Download ZIP**，或者：

```bash
git clone https://github.com/yoruake/nama-dictionary.git
```

### 2. 解压（下载 ZIP 的话，这一步最容易出错）

解压后你会得到一个 `nama-dictionary-main` 文件夹。**打开它，确认里面直接就有 `manifest.json`。**

Windows 资源管理器右键「全部解压缩」默认会多套一层，变成
`nama-dictionary-main\nama-dictionary-main\manifest.json`。
要加载的是**里面那个**含 `manifest.json` 的文件夹，不是外面那个。

### 3. 加载

1. 浏览器地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`）回车
2. 打开右上角的 **「开发者模式」**——不打开的话「加载已解压的扩展程序」按钮根本不出现
3. 点 **「加载已解压的扩展程序」**，选中第 2 步里那个含 `manifest.json` 的文件夹
4. 已经打开着的网页需要**刷新一次**才会生效

### 4. 填 API Key（必须，不填的话选词没有任何反应）

装好之后扩展还不能用，得先给它一个自己的 [DeepSeek](https://platform.deepseek.com) API Key：

1. 点工具栏的扩展图标（或在 `chrome://extensions` 里点 Nama 的「详细信息 ▸ 扩展程序选项」）打开设置页
2. 把 Key 粘进 `DeepSeek API Key` 输入框，点保存
3. 用设置页下方的 **「测试 API Key」** 验一下，能返回结果就说明通了

模型固定用 `deepseek-flash`（DeepSeek-V4.1-Flash，2026-09-10 起的当前型号；旧名 `deepseek-v4-flash`
对应的模型已退役，只是临时转发），并显式关闭了思考模式（`thinking: disabled`）——
默认开思考，查一个词要等好几秒，关掉之后才是可用的速度。

### 装不上 / 装上了没反应

| 现象 | 原因 |
|---|---|
| 「清单文件缺失或不可读」 | 选错文件夹了，见第 2 步的多套一层 |
| 找不到「加载已解压的扩展程序」按钮 | 开发者模式没打开 |
| 加载成功，但选词没有任何反应 | 多半是没填 API Key，见第 4 步；也可能是装扩展之前就打开着的旧页面，刷新一下 |
| 「测试 API Key」报错 | Key 错了，或者 DeepSeek 账户余额为 0 |
| 只在某些网页上没反应 | `chrome://` 开头的页面、扩展商店页面浏览器不允许注入脚本，这是浏览器的限制 |

### 从旧版本升级

「加载已解压的扩展程序」装上的扩展，身份是按**所在文件夹的路径**算出来的，API Key 和生词本都记在这个身份名下。
所以升级要**原地覆盖**：

1. 把新版的所有文件拷进你当初加载的那个文件夹，同名文件全部替换（`git clone` 装的直接 `git pull`）
2. 打开 `chrome://extensions`，点 Nama 卡片上的 **↻ 重新加载**
3. 已经打开着的网页刷新一次

这样 Key、生词本、收藏都会保留。0.8 及以前的词库在升级后第一次启动时会自动换成新的存法，不用手动处理。

**别**先「移除」再加载，也别从另一个文件夹重新加载——那等于装了个新扩展，Key 要重填，生词本是空的
（导出的 CSV 只能进 Anki，导不回 Nama）。

## 用法

在任意网页上用鼠标选中要查的词，查词卡片会浮现在选区旁边。选多少都行，单词、词组、整句都可以。

- 卡片**流式渲染**：先出词形，再逐字长出注音，然后词义、词源依次到位。还没到的字段显示 `…`。
- 扩展会自动抓取选区所在的整句作为上下文一起发给模型，所以判断句法作用时它知道前后文。
  取的是网页**显示出来的**文字（`innerText`）：HTML 源码里的折行不算断句，`<br>` 和换段才算。
  0.8 用的是 `textContent`，源码里折行的长句会被切成几个词、`<br>` 两边的词会粘在一起，0.9 起修好。
- 点卡片上的星标收藏进生词本；已收藏的词再选一次就能取消收藏。
- 纯数字（日期、电话、ISBN、价格，含波斯/阿拉伯数字）和整段就是网址、邮箱、域名的选区不查——多是复制时顺手选中的；句子里带个链接的照常查。
- 「重新分析」按钮常驻，想换个结果时点它，新结果会替换旧的，收藏和导出状态保留。
- 生成中途关掉卡片也没关系，后台照样生成完存进缓存。
- 全屏页面里也能用（卡片会挂到全屏元素里）。

### 锁定正文语言

卡片上的下拉框选「正文语言」，默认「自动识别」。读塔吉克语、达利语这类和近亲语言共用文字的材料时，
锁定之后模型只按这门语言分析，不会在波斯语／塔吉克语／俄语之间来回跳。
选择对所有页面生效、会记住，换材料时再改回来；切换后当前词会按新语言重查（该语言已查过的直接出缓存）。

### 读音（IPA）

模型先写出标好元音和重音的形式（如 кни́ги、ketāb），再据此给 IPA，不再逐字母硬转。
单个词还会同时去 [kaikki.org](https://kaikki.org)（Wiktionary 数据）查词典读音：同形词、方言变体都作为候选，
挑和模型读音最接近的那个替换进去，读音后面带 ✓ 的就是取自 Wiktionary 的。
词典和模型同时查，不拖慢出结果：模型一写完卡片就定稿，词典读音随后到了再就地换上（通常不到一秒）。
词典里没有（常见于变格变位形式）、差得太远或 4 秒内没查到，就保留模型的读音。
中文、日语、韩语、印地语、梵语仍用拼音／罗马字／IAST，不查词典。

> 结果的准确度很吃上下文。孤立的一个汉字、一个阿拉伯字母词天生有歧义，
> **连着前后文一起选**会明显更准。

### 页内高亮

默认开启。生词本里的词会在网页上带点线下划线，**纯被动显示**——不响应悬停、也不响应点击，
想查还是照常选中它。收藏 / 取消收藏会即时增删下划线。

匹配的是精确表面形式，不做词形还原：收藏的是 `books`，页面上的 `book` 不会被标出来。

### 设置项

| 设置 | 默认 | 说明 |
|---|---|---|
| DeepSeek API Key | 空 | 必填 |
| 网页内高亮 | 开 | 改动后刷新网页生效 |
| 本地缓存 | — | 能看已缓存词条数并清空（收藏的词不会被清掉） |
| 测试 API Key | — | 填个测试词验证连通性 |

## 生词本与 Anki 导出

设置页点「打开生词本」。支持搜索、按语言筛选、时间筛选（今天 / 近 7 天 / 近 30 天）、
导出状态筛选（未导出 / 已导出）、排序、展开详情、多选批量删除（勾选框 + Shift 范围选）。

点「导出 CSV」下载 `vocabulary_YYYY-MM-DD.csv`，**所见即所导**——跟随当前筛选。
导出后自动标记为「已导出」，下次筛「未导出」就只导新词。

导入 Anki：

1. 文件 → 导入 → 选该 CSV
2. Note Type 选「基础」
3. 字段映射：第 1 列 → 正面，第 2 列 → 背面，第 3 列 → 标签
4. **重复项处理选「保留(Preserve)」**

正面埋了隐藏的词条 id 用于去重，`#tags column:3` 会自动映射标签。

## 隐私

- API Key 只存在本机的 `chrome.storage.local` 里。
- Key 不会上传到任何第三方，只在调用 DeepSeek 时作为认证头发给 DeepSeek。
- 查词时会把**选中的词和自动提取的上下文句子**发给 DeepSeek 用于生成分析。
- 选中的是单个词时，还会把**这个词本身**（不含上下文）发给 kaikki.org 查 Wiktionary 读音。
- 查词记录、生词本、缓存全部保存在本地。
- **没有远程统计、埋点或自建后端。** 代码里也不含任何 Key。

## 权限

| 权限 | 用途 |
|---|---|
| `storage` | 保存 API Key、查词缓存、生词本和锁定的正文语言 |
| `https://api.deepseek.com/*` | service worker 调 DeepSeek |
| `https://kaikki.org/*` | 查 Wiktionary 词典读音 |
| `<all_urls>` content script | 在网页上监听选词、显示卡片、画高亮下划线 |

## 已知局限

- 页内高亮：被拆进多个内联标签的词匹配不到；跨标签页的高亮不实时同步，需刷新。
- 提示词改动只对**新查的词**生效，旧词要点「重新分析」才更新。
- `chrome://`、扩展商店等浏览器保留页面上无法注入脚本，用不了。

## 项目结构

```
├── manifest.json            MV3 清单
├── langs.js                 正文语言列表（卡片下拉框 + 词典查询共用）
├── background.js            service worker：DeepSeek 调用、提示词、解析、词典读音、词条存储
├── content.js / .css        网页划词卡片 + 页内高亮
├── check.js                 自检：node check.js（加 --live 真连 kaikki.org），扩展不加载它
├── options.html/js/css      设置页
├── vocabulary.html/js/css   生词本
└── icons/
```

## 词条数据结构

```js
{ id, word, translit, ipaDict, etymology, meaning, form, lang, context, timestamp, starred, exportedAt }
```

`word` 存的是**你选中的原文词形**，不是模型返回的词典形——页内高亮要靠它做精确匹配。
`ipaDict` 为 true 表示 `translit` 里的 IPA 取自 Wiktionary。锁定正文语言时 `lang` 就是锁定的语言名。

存法：每个词形一个键 `w:<小写词形>`，值是这个词形的所有词条（不同语言、重新分析过的）；
另有 `starredWords`（收藏的词，页内高亮用）。0.8 及以前整本词库存在一个 `entries` 键里，
词条一多（几千条、几 MB）每查一次都要整读整写，命中缓存也要 200ms 以上；升级后第一次启动会自动拆开，数据不丢。
